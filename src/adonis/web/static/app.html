How it works

      

        Ingest → Extract claims (LLM + GLiNER) → Candidates (bge-small + FAISS + entity hybrid, ordered a<b) → Judge (LLM, judge_v1) → Verify (verbatim + fuzzy + entailment) → Flags.
        Dedupe by content hash, ordered pairs prevent duplicates. Flags only surface after overall_pass. See api/settings for live config.
